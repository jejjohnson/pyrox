# SSM API

`pyrox-ssm` is the package whose inference recurses in time: [pyrox-gp](gp.md) solves over all N points at once, [pyrox-lgm](lgm.md) solves one sparse precision, and `pyrox_ssm` runs a filter and smoother over the time axis. This page is a stub until the first names land in `pyrox_ssm`, which currently exports nothing.
