    Capability index¶

    Every public name in the five pyrox packages (263 of them), each listed once at its public home and grouped by the module that defines it, with the first sentence of its docstring; then the public API of gaussx, kernellib, geonnax and functax, which the packages build on. Search this page before writing a helper: if what you need is here, compose it; if it is almost here, extend it where it lives. Regenerate with make capabilities after changing a public API (packages/pyrox/tests/test_capabilities.py checks it is current).
