- **Provides.** Extreme value distributions (GEV, GPD and their special cases) that work as NumPyro likelihoods, stable pure-JAX densities, quantiles and return levels, point processes for event times, and block-maxima, threshold and declustering steps on xarray.
- **Start from.** `pyrox_xtreme.GeneralizedExtremeValueDistribution`, `pyrox_xtreme.GeneralizedParetoDistribution`, `pyrox_xtreme.gev_return_level`, `pyrox_xtreme.gpd_return_level`, `pyrox_xtreme.extraction.temporal_block_maxima`, `pyrox_xtreme.extraction.quantile_threshold`, `pyrox_xtreme.extraction.decluster_runs`, `pyrox_xtreme.point_processes.distributions.HomogeneousPoissonProcess`.
- **Keep.** The shape parameter ξ is `concentration` and ξ > 0 means a heavy tail, so a scipy comparison uses `genextreme(c=-ξ)`; start NUTS with `init_to_median`; pass every random draw its own key.
- **Never.** Write a GEV or GPD density with `numpyro.factor` or compute a tail as `1 - cdf`; use the pyrox-xtreme distribution as a sample site with `obs=` and the survival and return-level functions.
- **Open the skill when.** You model non-stationary return levels, Hawkes, renewal, marked or spatial point processes with padded event buffers, spatial extremes, or need the declustering and extremal-index options.
